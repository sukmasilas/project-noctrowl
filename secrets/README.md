# secrets/

This folder holds credential files that shouldn't be committed (Google Cloud
credentials, primarily). Everything in this folder except this README is gitignored
(both by the explicit `secrets/*` rule and by the repo-wide `*.json` rule, since all
files below are JSON).

Expected contents:
- `google-service-account.json` — Drive API scope only (Sheets API is not needed for
  this project). Read-only in practice: a service account has no storage quota on a
  personal Gmail Drive, so it can list/download but not create/upload — see
  `.env.example`'s Google Cloud section. Kept for the read-only path and in case the
  project ever moves to Google Workspace + Shared Drives.
- `google-oauth-client-secret.json` — the OAuth "Desktop app" client secret downloaded
  from Google Cloud Console. Not sensitive by itself in the way a password is (it's a
  public-client secret, not a bearer credential), but treat it as private anyway — see
  `.env.example`'s Google Cloud section for setup steps.
- `google-oauth-token.json` — generated by running `scripts/authorize_google_drive.py`
  once, locally. Contains an access token and a refresh token for the Google account
  that ran the script (the account that owns the "Finance & Accounting" Drive folder).
  This one IS sensitive — it's what actually lets the app read/write Drive under that
  account's quota. Re-generate by re-running the script if it's ever lost or revoked.
